# 마음의 향기 타로 홍보영상

- `ai-smell-promo.mp4` — 1920×1080, 30fps, 약 52초, 배경음악 + 하단 자막 포함
- 실제 앱 화면을 컴퓨터에서 직접 실행해 녹화한 뒤, 자막과 함께 편집했습니다.
  (감정 색 고르기 → 주제 고르기 → 카드 세 장 뽑기 → 리딩 결과 → 더 물어보기 → 향기 추천 → 선생님용 향기 목록·도움말)
- `ai-smell-promo.srt` — 자막 파일 (유튜브 등에 따로 올릴 때 사용)
- `source/` — 다시 만들 때 쓰는 녹화·편집 스크립트 (앱 배포에는 영향 없음)

## 참고
- 영상 속 "더 물어보기" 답변은 API 키 없이 실행했을 때 앱이 보여주는 **미리 준비된 답변**입니다.
  (선생님이 설정에서 키를 넣으면 이 자리에 AI 답변이 나옵니다.)
- 앱 주소(URL)는 저장소에서 찾지 못해 영상에 넣지 않았습니다.
- 배경음악은 프로그램으로 직접 만든 곡이라 저작권 걱정 없이 쓰셔도 됩니다.

## 다시 만들 때 (개발용 메모)
1. 저장소 폴더에서 `python3 -m http.server 3000` 으로 앱 실행
2. `SEED=3 SLOW=4 node go2.mjs` — 화면 녹화 (애니메이션을 4배 느리게 녹화)
3. 각 클립을 `setpts=PTS/4,fps=30` 으로 `frames/<클립>/` 에 풀고, `assets/` 에 카드 이미지·글꼴 복사
4. `python3 music.py` → `node render.mjs` → ffmpeg로 `out/*.jpg` + `music.wav` 합치기
